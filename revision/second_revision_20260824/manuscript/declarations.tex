\subsection*{Availability of data and materials}
\begin{roundtworevision}
The tumor disease signatures used in this study were derived from publicly available TCGA data accessed through the Genomic Data Commons (\url{https://portal.gdc.cancer.gov/}). Pharmacological perturbation profiles were obtained from LINCS L1000 (GEO accession GSE92742). DepMap Public 26Q1 was obtained from the DepMap portal, and structures 4LXZ and 4BKX were obtained from the RCSB Protein Data Bank. Source code, split-generation scripts, training and analysis scripts, machine-readable manifests, selected checksums, plotting data, and publicly redistributable processed outputs are available at \url{https://github.com/DCarchimonde/PanCancer-MultiModal-HDAC} on the \texttt{major-revision-2026} branch. The corrected analysis evidence is archived at commit \texttt{fefbf2f4fa7399983d4d4041dcb8e7e91b84d17f}, and the first-round submission snapshot at commit \texttt{0eb798f}. Repository documentation distinguishes original outputs, revision-regenerated analyses, retained derived evidence, large nonredistributed inputs or run artifacts, and intermediates that are no longer available. Reported values can be verified against archived machine-readable evidence and the submission documents recompiled from frozen table and figure assets; however, a self-contained bitwise rerun of every training and screening stage from the GitHub repository and current public inputs alone is not guaranteed because large GPU checkpoints and prediction arrays and specified analysis-time intermediates were not retained in the portable archive. Large primary public datasets are not redistributed because of file size and source-specific access terms. Stage-specific requirements and limitations are documented in \texttt{REPRODUCIBILITY.md}. Additional file 1 contains supplementary methods, tables, and figure notes; Additional file 2 contains the machine-readable revision tables.
\end{roundtworevision}
