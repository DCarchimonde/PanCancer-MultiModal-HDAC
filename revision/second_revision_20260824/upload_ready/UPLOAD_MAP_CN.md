# BMC Bioinformatics 二审上传对照表

本目录中的文件均为第二轮小修经共同作者终审核对后的版本（2026-08-27）。上传前请先删除或替换投稿系统中沿用的上一轮文件，不要仅凭同名文件判断版本。

| 投稿系统栏目 | 上传文件 | 说明 |
|---|---|---|
| Point-by-point response | `Response_to_Reviewers.pdf` | 必传；逐点回复 Reviewer 1 与 Reviewer 3 |
| Manuscript file | `Manuscript_LaTeX_Source.zip` | 必传；可编辑 LaTeX 源码，顶层直接包含 `manuscript/`、`response/`、`supplement/`、`scripts/` 等 |
| Supplementary material | `Additional_file_1_Supplementary_Material.pdf` | 替换上一轮 Additional file 1 |
| Supplementary material | `Additional_file_2_Revision_Tables.xlsx` | 替换上一轮 Additional file 2 |
| Related files | `Revised_Manuscript_Reviewer_Marked.pdf` | 供编辑和审稿人核对修改；不随论文正式发表 |

`Clean_Revised_Manuscript_Reference_Only.pdf` 仅供作者和导师本地核对编译结果。投稿系统以 LaTeX ZIP 作为 manuscript file 时，不要再把该 PDF 重复上传为主稿。

Figures and tables separately 为可选栏目；本轮图表已包含在 LaTeX 源码包中，无须重复上传。

上传完毕后，在进入下一页前逐项确认：

1. Point-by-point response 栏目中已经显示新的回复 PDF；
2. Manuscript file 已替换为本目录的 LaTeX ZIP；
3. 两个 Supplementary material 均已替换；
4. Related files 已替换为新的 reviewer-marked PDF；
5. 页面不存在误留的上一轮同类文件。
